OrynSDK ToDo2 reset: 0.5.191

This file is now the runtime SDK work list. The previous entries overstated readiness by counting proofs, manifests, placeholders, and foundations as completion. From this reset forward, almost everything remains [TOBE] until the SDK can emit, build, link, package, and run the real module code needed by the kernel and userland.

Status tags:
[ OK ] Works for the current narrow scope and is not just a proof/stub.
[WARN] Exists partially, or works only as a foundation/smoke path.
[FAIL] Known broken or blocking.
[TOBE] To Be Implemented for the real runtime SDK.

Current narrow OK scope:
[ OK ] UEFI x64 loader can load the kernel ELF and pass one plain OrynBootInfo pointer.
[ OK ] Kernel-5 has a plain KernelMain source file.
[ OK ] The old ORYN_KERNEL_APPLICATION registration is removed from Kernel-5.
[ OK ] KernelMain returns bool for success/failure where that is the appropriate result.
[ OK ] KernelMain can write Hello World with printf for the smoke path.
[ OK ] Kernel-owned entry support owns the platform bridge around KernelMain.

Important warnings:
[WARN] The current printf path is a smoke path, not a completed stdout/console/device runtime.
[WARN] LibC function manifests exist, but LibC is not yet a complete runtime SDK library stack.
[WARN] Kernel module manifests exist, but they are not enough: modules must emit real code into kernel, userland services, libraries, apps, and devices.
[WARN] Existing proof output must not be treated as runtime SDK completion.
[WARN] Existing driver foundations must not be treated as completed runtime drivers.

Runtime SDK principle:
[TOBE] A module is not done when it has a manifest.
[TOBE] A module is done when selecting it makes the SDK add the required kernel code, userland services, userland libraries, device drivers, startup order, package files, and testable runtime behaviour.
[TOBE] The SDK must build the OS graph, not just validate it.

7. Public return rule:
[TOBE] Public functions return bool when the only meaningful result is yes/no success.
[TOBE] Public functions return OrynStatus when success/failure needs a code/message.
[TOBE] Public functions return OrynXxxResult when they produce a value plus status.
[TOBE] No public start/stop/create/open/read/write/load/launch/allocate/map/mount/register/send/receive/parse/validate function returns void.
[TOBE] Generated startup checks all returns.
[TOBE] Generated services check all returns.
[TOBE] Userland client libraries expose checkable returns.
[TOBE] Audit tool scans public headers and fails unchecked public void APIs.
