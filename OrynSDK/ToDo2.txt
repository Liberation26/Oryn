OrynSDK ToDo2: runtime SDK percentage tracker 0.5.193

This file tracks real runtime SDK completion using percentages instead of OK/WARN/TOBE tags.

Completion scale:
[100%] Implemented and accepted for the current runtime SDK direction.
[ 75%] Mostly implemented, but still needs cleanup, integration, or wider proof.
[ 50%] Partial working foundation exists, but it is not complete runtime SDK behaviour.
[ 25%] Early scaffold, smoke path, proof path, or concept exists.
[  0%] Not implemented yet for the runtime SDK.

Rule:
A module is not complete because it has a proof, manifest, placeholder, or boot report line. A module is complete only when selecting it makes the SDK emit/include the required kernel code, userland services, userland libraries, device drivers, startup order, package files, and testable runtime behaviour.

[100%] Kernel-5 has a plain KernelMain source file.

[ 25%] Kernel-owned entry support owns the current platform bridge around KernelMain.
[ 25%] Runtime SDK direction now includes a real kernel-used selected-module startup path; full module emission is still separate work.
