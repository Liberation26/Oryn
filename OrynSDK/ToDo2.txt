OrynSDK ToDo2 - Freestanding SDK and Linux-like Kernel Roadmap
Version: 0.5.91
Updated from package: 0.5.91 Generated Module Manifest Ownership
Purpose: Track the SDK work needed to grow OrynWsl from the current boot-proven UEFI x64 kernel into a full freestanding SDK and small Linux-class operating system.

Meaning of "Linux-like":
Oryn is not meant to copy Linux source code or become a Linux distribution.
Oryn is meant to provide the same kind of kernel capability that makes Linux useful:
- protected processes;
- pre-emptive multitasking;
- user/kernel isolation;
- a virtual filesystem;
- block devices and filesystems;
- external userland programs;
- a network stack;
- drivers bound through a device model;
- stable kernel/user ABI;
- diagnostics, logging, panic, crash, and recovery paths;
- repeatable builds and automated boot tests.

Meaning of "SDK":
The SDK is the source, build, boot, image, test, and support layer used to create freestanding kernels and operating systems.
It must stay native-C-first and must not depend on .NET, managed runtimes, or hosted operating-system services inside the kernel path.

[ OK ] KernelRuntimeBootSequence now has one runtime duty: enter the kernel runtime and hand off to the boot proof runner.
[ OK ] Added KernelBootProof.h as the ownership boundary for boot proof sequencing.
[ OK ] Added KernelBootProofOrchestrator.c to own boot proof execution, panic handoff, running-state transition, and halt proofs.
[ OK ] KernelRuntimeBootSequence no longer includes KernelDiagnostics, KernelLifecycle, KernelPanic, or KernelIo.


0.5.88 FAT32 and VFS production filesystem foundation:
[ OK ] FAT32 mount validation now checks BPB layout, sector count, reserved sectors, FAT count, cluster sizing, root cluster, total sectors, and unsupported FAT12/FAT16 root-entry layouts.
[ OK ] FAT32 volume state now exposes Mounted, ReadOnly, LastStatus, FsInfoSector, BackupBootSector, free-cluster hint, and next-free hint.
[ OK ] FAT writes now preserve the high nibble, mirror all FAT copies, and return explicit status failures.
[ OK ] FAT allocation now uses next-free hints and maintains free-cluster estimates when FSInfo is valid.
[ OK ] FAT chain safety now validates cluster links and rejects out-of-range chains.
[ OK ] File writes now free old clusters when a file shrinks or becomes zero bytes.
[ OK ] Create/write/delete now reject invalid 8.3 paths, root deletion, duplicate creation, missing parents, and non-empty directory deletion.
[ OK ] VFS now normalizes paths, rejects backslash and dot/dot-dot traversal, chooses the longest matching mount prefix, blocks duplicate mounts, and exposes VFS status reporting.
[ OK ] Added OrynFat32CheckVolume, OrynFat32Flush, OrynFat32GetFreeClusterEstimate, OrynFat32ValidatePath, OrynFat32LastStatus, OrynVfsNormalizePath, and OrynVfsLastStatus.
[WARN] Long filename support, journaling, permissions, caching, real device hotplug, fsck repair, and full POSIX file descriptors are still future filesystem layers, not claimed complete in this step.

[ OK ] Formatter now writes a valid FAT32 media descriptor before mount validation.
[ OK ] Formatter now writes backup boot and FSInfo sectors for the declared backup locations.
