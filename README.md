#Oryn, the Freestanding Operating System SDK
Welcome to the Oryn's Code Tree. Here we are creating the first, true, OS SDK. It is currently for Native C coders, but the front end languages will be increased to Visual Basic, C#, C++, and many other languages. And the output, your actual OS, is currently written in Native C, but that output languae will also be increased to include Ada, ASM, C++, Rust and many more.
